# Teste Técnico - Frontend Estapar

Este projeto é uma aplicação frontend desenvolvida como parte do processo técnico para a Estapar, implementando funcionalidades de gestão de garagens e planos de estacionamento.

# Deploy

Para acessar o projeto: https://estapar-frontend.vercel.app

## 📋 Funcionalidades Implementadas

### 1. Lista de Garagens

### 2. Gestão de Vagas e Planos

### 3. Cadastro e Edição de Planos

# 🛠️ Tecnologias Utilizada

  - Next.js - Framework React
  - TypeScript - Tipagem estática
  - Tailwind CSS - Estilização
  - shadcn/ui - Componentes UI
  - React Hook Form - Gerenciamento de formulários
  - Zod - Validação de schemas
  - Clean Architecture (SOLID) - Organização do código
